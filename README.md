## 🛠 实战项目

- **17-项目-通讯录管理系统**：结构体 + 指针 + 函数封装的综合练习（增删改查、清空、按姓名排序）

## 📝 编码说明

全库源码统一为 **UTF-8（带 BOM）**，中文注释可跨平台正常显示。

## 💡 学习笔记

- 编码判断靠字节级严格校验，不靠肉眼；
- 批量改名先查后改、改完终验；
- 破坏性操作前先 commit，git checkout 是终极后悔药。
